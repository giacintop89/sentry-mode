Loading devices…

“Session default” follows PipeWire; naming a device instead makes the node fail loudly when that device is missing. Changing the camera needs video and Sentry stopped; size, rate, format and exposure apply to the next frame a running capture takes. A pinned exposure holds the device at that value; 0 leaves it to choose one per scene. A compressed format is what lets a device reach its higher rates, and the size and rate have to be a pair the device offers — ./scripts/detect_camera.sh lists them. A separate sentry-mode run picks up changes on restart.
