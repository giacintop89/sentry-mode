Voice modification

Microphone is off. Enable it to talk or record a message to Captures.

The phone microphone needs HTTPS. Open the secure app address after the one-time setup below.

Set up this phone
  1. Download the Sentry Mode local certificate on this phone.
  2. iPhone: install the profile in Settings → General → VPN & Device Management, then enable Sentry Mode Local CA in Settings → General → About → Certificate Trust Settings.
  3. Android: in Settings, search “Install a certificate”, choose CA certificate and select the file. The menu name varies by phone.
  4. Open the HTTPS link above, tap Enable mic and allow microphone access.

The certificate trusts only this node. Keep the app on your trusted local network.
