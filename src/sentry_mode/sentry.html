    Telegram setup and delivery

    The chat ID is the number from an update your bot received, or a public channel @username; the bot needs permission to send there. Enter the token over this app’s HTTPS address: it is stored privately on the node, never returned to the browser, and leaving the field blank keeps it.

    Test mode needs no credentials; live sending needs both token and chat ID. Messages follow the rule’s confirmation, cooldown and rearming settings. Failures are logged and never retried. Disarming cancels pending sends, though a message already submitted may still arrive.

    Saved SSH commands

    Use a host or SSH alias this node can already reach with key authentication. Commands run exactly as saved, with no detection data inserted.

    SSH setup and stopping behavior

    Set up key-based access from the node’s normal user account and verify the host key first. Sentry reuses the existing SSH configuration and known hosts: it never asks for a password, accepts an unknown host key or retries a failure.

    Disarming stops pending actions and the local SSH process. A command already started on the remote machine keeps running.
